The letters A, B and C try to defeat the letter Z. Their goal is to leave no place for the Z to go. The Z tries to be on the left side of the other three letters on the x-axis. 
  The structure of the playing field and the initial placement of the letters:
    X A - - X
    B - - - Z
    X C - - X

The dashes show that the letters can be moved.
  The Z can move in any direction.
  The A, B and C can only move forward, no backward movement is allowed.
  Each of the up, down, right, left and diagonally moves are counted as 1 unit.

The “X”s indicate that the forbidden places to move.

The user enters the maximum number of moves, if this number is exceeded, then the game ends in a draw.

The user also enters the first turn of the move ("last" for Z, "firsts" for A, B or C), then the turn changes sequentially.

If the user wants to play A, B or C backwards, or play a letter on forbidden or full places, or play more than 1 unit, this would be an invalid move.

If Z is further left on the x-axis than all the other letters, Z wins the game. If it is not the letter Z's turn in the game and the opposing side makes the letter Z unable to move with their move, the opposing side wins the game.
